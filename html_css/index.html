Condiciones de préstamo

Información básica que debe conocer quien solicita un recurso.

Consultar las condiciones de préstamo
  • La solicitud debe indicar quién utilizará el recurso y para qué actividad académica.
  • El recurso debe devolverse en la fecha acordada y en las condiciones en que fue entregado.
  • Quien recibe el recurso debe informar oportunamente cualquier daño o problema detectado.
  • La disponibilidad real debe confirmarse con la unidad responsable antes de retirar el equipo.

Estas condiciones son ilustrativas y no representan una política institucional oficial.

Recomendaciones de uso

  • Verifica el código y el estado del recurso antes de solicitarlo.
  • Comprueba que estén incluidos los cables, cargadores y accesorios necesarios.
  • Devuelve los equipos dentro del plazo acordado.

Preguntas frecuentes

Respuestas breves sobre este prototipo.

¿Puedo solicitar un recurso desde esta página?

No todavía. Esta versión presenta la interfaz, pero no incluye una operación real de solicitud.

¿Los datos se guardan?

No. Para guardar datos se necesitaría implementar la lógica correspondiente y conectarla con un servidor.
